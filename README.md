# World Express Group

Virtual airline website for World Express Group — a VATSIM virtual airline combining a oneworld-style passenger network with a FedEx-style express cargo division.

## Pages
- `index.html` — Home
- `network.html` — VATSIM network & pilot requirements
- `fleet.html` — Fleet (11 aircraft types)
- `divisions.html` — Passenger & cargo divisions
- `alliance.html` — oneworld + FedEx concept explainer
- `newsroom.html` — News

## Logo
Add your logo file to this repo root as `logo.png` — it's referenced in the header/footer of every page.

## Deploy
Static site, no build step required. Deployed via Vercel.
